# Tiny-Workers Dispatcher

Invoke `$tiny-pm` immediately and follow it for planning, execution, approvals, choices, and verification.

Use another Tiny-Workers skill when its focused workflow matches the request. Keep Tiny-PM in control of shared workflow and safety decisions. If no other collection skill applies, use Tiny-PM alone.
